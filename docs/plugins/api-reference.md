# Plugin API reference

Generated by `pnpm generate:plugin-api` from src/features/plugins/api-table.ts. Do not edit by hand.

Plugin API version: `0.1.9`. Before 1.0 there is no compatibility promise.

Every method returns a promise. A refused call rejects with a `PluginApiError` whose `code` is one of:

- `permission-denied`
- `unknown-method`
- `invalid-params`
- `rate-limited`
- `plugin-stopped`
- `library-unavailable`
- `conflict`
- `not-implemented`
- `message-too-large`
- `network-error`
- `internal-error`
- `user-action-required`
- `file-missing`
- `file-needs-permission`

A `permission-denied` error also names the missing Plugin Permission in `permission`.

### `library.search`

Searches the Library's text with the same query and switches as Library Search: one row per matching item with a snippet, match counts, and a cursor for the next page. An invalid Regex comes back as an invalid-regex error, never a refusal. When bookId is given, only that Book's items come back and a page may hold fewer than limit results; follow nextCursor until it is absent. Canvases carry no Book, so a bookId filter never returns one.

- Plugin Permission: `library:read`
- Effect: read
- Refused with `library-unavailable` while the Library cannot be read or written

Input:

```ts
{
  query: string;
  matchCase?: boolean;
  wholeWord?: boolean;
  regex?: boolean;
  kinds?: ("book" | "chapter" | "note" | "canvas")[];
  bookId?: string;
  limit?: number;
  cursor?: string | null;
}
```

Output:

```ts
{
  results: ({
    kind: "book";
    /** Pass to library.books.get. */
    bookId: string;
    title: string;
    snippet: {
      text: string;
      /** [from, to) ranges inside text, in order. */
      highlights: {
        from: number;
        to: number;
      }[];
    };
    /** The first match's offset inside the block the snippet came from. */
    firstMatchOffset: number;
    /** Total matches across every block of the item. */
    matchCount: number;
  } | {
    kind: "chapter";
    /** Pass to library.chapters.get. */
    chapterId: string;
    bookId: string;
    title: string;
    snippet: {
      text: string;
      /** [from, to) ranges inside text, in order. */
      highlights: {
        from: number;
        to: number;
      }[];
    };
    /** The first match's offset inside the block the snippet came from. */
    firstMatchOffset: number;
    /** Total matches across every block of the item. */
    matchCount: number;
  } | {
    kind: "note";
    /** Pass to library.notes.get. */
    noteId: string;
    /** Null when the Note is Unfiled. */
    bookId: string | null;
    title: string;
    snippet: {
      text: string;
      /** [from, to) ranges inside text, in order. */
      highlights: {
        from: number;
        to: number;
      }[];
    };
    /** The first match's offset inside the block the snippet came from. */
    firstMatchOffset: number;
    /** Total matches across every block of the item. */
    matchCount: number;
  } | {
    kind: "canvas";
    /** Pass to library.canvases.get. */
    canvasId: string;
    /** The card the snippet came from; absent for a title hit. */
    cardId?: string;
    title: string;
    snippet: {
      text: string;
      /** [from, to) ranges inside text, in order. */
      highlights: {
        from: number;
        to: number;
      }[];
    };
    /** The first match's offset inside the block the snippet came from. */
    firstMatchOffset: number;
    /** Total matches across every block of the item. */
    matchCount: number;
  })[];
  /** Pass as cursor for the next page; absent when done. */
  nextCursor?: string;
} | {
  error: "invalid-regex";
  message: string;
}
```

## network

### `network.fetch`

Fetches a URL on a granted host. A header can name a stored secret the host injects. A redirect is refused, so a granted host cannot forward the request, or an injected secret, to another host.

- Plugin Permission: `network:<host>` matching the URL's host
- Effect: write

Input:

```ts
{
  url: string;
  method?: "GET" | "POST" | "PUT" | "PATCH" | "DELETE" | "HEAD";
  headers?: Record<string, string>;
  /** Header name to secret name; the host fills in the value. */
  secretHeaders?: Record<string, string>;
  body?: string;
}
```

Output:

```ts
{
  status: number;
  statusText: string;
  headers: Record<string, string>;
}
```

Then the body, as chunks passed to `listener.onChunk` until `listener.onEnd`:

```ts
{
  /** The next piece of the response body, decoded as UTF-8. A chunk is at most 64 KB. */
  text: string;
}
```

```ts
  grant: string;
  offset: number;
  length: number;
}
```

Output:

```ts
ArrayBuffer
```

### `files.stat`

Reads a File Grant's name, size, and last-modified time without reading its bytes, so a Plugin can mark a missing file.

- Plugin Permission: `files:pick`
- Effect: read

Input:

```ts
{
  grant: string;
}
```

Output:

```ts
{
  name: string;
  size: number;
  /** Milliseconds since the Unix epoch. */
  modified: number;
}
```

### `files.requestAccess`

Asks for read access to a File Grant again, inside the author's click or Command run. On the web the browser asks the author; on desktop it always returns true.

- Plugin Permission: `files:pick`
- Effect: read

Input:

```ts
{
  grant: string;
}
```

Output:

```ts
boolean
```

Ends a File Grant. The author's file itself is never deleted or changed.

- Plugin Permission: `files:pick`
- Effect: write

Input:

```ts
  grant: string;
```

```ts
null
```

## Events

Subscribe with `maibuk.on(event, listener)`; it resolves with the function that unsubscribes. An event reaches the Plugin only while it holds the event's Plugin Permission, and never while it is stopped. Events only invalidate: they carry ids, never content.

### `library.changed`

A Book, Note, or Canvas was saved (Chapter edits arrive as their Book), or a bulk operation replaced the Library.

- Plugin Permission: `library:read`

Payload:

```ts
{
  entity: "book" | "note" | "canvas";
  id: string;
  origin: "local" | "remote";
  kind: "content" | "metadata";
} | {
  scope: "all";
  reason: "restore" | "resetLibrary" | "databaseLoad";
}
```

### `library.availabilityChanged`

The Library became available or unavailable (the Tutorial makes it unavailable).

- Plugin Permission: none

Payload:

```ts
{
  available: boolean;
  /** Why availability changed; the Tutorial is the only reason today. */
  reason?: "tutorial";
}
```

### `language.changed`

Maibuk's language changed. The current value is delivered on subscription, so a Plugin that starts after a change never misses it.

- Plugin Permission: none

Payload:

```ts
{
  language: string;
}
```

### `endpoint.addressChanged`

This Plugin's Plugin Endpoint address changed: the listener moved to another port or stopped. The current address is delivered on subscription, so a Plugin that starts after a change never misses it.

- Plugin Permission: `serve`

Payload:

```ts
{
  url: string | null;
}
```

### `permissions.changed`

This Plugin's Plugin Permissions changed: one was granted or revoked. The current list is delivered on subscription, so a Plugin that starts after a change never misses it.

- Plugin Permission: none

Payload:

```ts
{
  permissions: string[];
}
```

### `editor.contentChanged`

The target editor's content or language changed; sent once per typing burst.

- Plugin Permission: `editor:read`

Payload:

```ts
{
  entity: {
    kind: "book" | "chapter" | "note" | "canvas" | "ephemeral";
    id: string;
  };
}
```

### `editor.focusChanged`

The target editor changed: another took focus, or the only one on screen mounted or unmounted (entity is null when there is none).

- Plugin Permission: `editor:read`

Payload:

```ts
{
  entity: {
    kind: "book" | "chapter" | "note" | "canvas" | "ephemeral";
    id: string;
  } | null;
}
```
