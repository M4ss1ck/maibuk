# Plugin API reference

Generated by `pnpm generate:plugin-api` from src/features/plugins/api-table.ts. Do not edit by hand.

Plugin API version: `0.1.0`. Before 1.0 there is no compatibility promise.

Every method returns a promise. A refused call rejects with a `PluginApiError` whose `code` is one of:

- `permission-denied`
- `unknown-method`
- `invalid-params`
- `rate-limited`
- `plugin-stopped`
- `library-unavailable`
- `not-implemented`
- `message-too-large`
- `internal-error`

A `permission-denied` error also names the missing Plugin Permission in `permission`.

## library

### `library.books.list`

Lists every Book in the Library.

- Plugin Permission: `library:read`
- Effect: read
- Refused with `library-unavailable` while the Library cannot be read or written

Input:

```ts
Record<string, never>
```

Output:

```ts
{
  id: string;
  title: string;
  subtitle: string | null;
  authorName: string;
  language: string;
  wordCount: number;
  /** Milliseconds since the Unix epoch. */
  updatedAt: number;
}[]
```

## editor

### `editor.getContent`

Reads the focused rich-text editor's content, or no-target when none is focused.

- Plugin Permission: `editor:read`
- Effect: read

Input:

```ts
Record<string, never>
```

Output:

```ts
{
  status: "ok";
  entity: {
    kind: "book" | "chapter" | "note" | "canvas";
    id: string;
  };
  content: {
    /** Plain text. */
    text: string;
    /** Sanitized HTML. */
    html: string;
  };
} | {
  status: "no-target";
}
```

### `editor.getSelection`

Reads the focused editor's selection as plain-text offsets.

- Plugin Permission: `editor:read`
- Effect: read

Input:

```ts
Record<string, never>
```

Output:

```ts
{
  status: "ok";
  entity: {
    kind: "book" | "chapter" | "note" | "canvas";
    id: string;
  };
  range: {
    from: number;
    to: number;
  };
  text: string;
} | {
  status: "no-target";
}
```

### `editor.reveal`

- Plugin Permission: `editor:read`
- Effect: read

Input:

```ts

    to: number;
  };
}
```

Output:

```ts

} | {
  status: "no-target";
}
```

Output:

```ts

  status: "no-target";
```

## network

### `network.fetch`

Fetches a URL on a granted host. A header can name a stored secret the host injects.

- Plugin Permission: `network:<host>` matching the URL's host
- Effect: write

Input:

```ts
{
  url: string;
  method?: "GET" | "POST" | "PUT" | "PATCH" | "DELETE" | "HEAD";
  headers?: Record<string, string>;
  /** Header name to secret name; the host fills in the value. */
  secretHeaders?: Record<string, string>;
  body?: string;
}
```

Output:

```ts
{
  status: number;
  statusText: string;
  headers: Record<string, string>;
}
```
